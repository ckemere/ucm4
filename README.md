# CM4-uSAW

Raspberry Pi Compute Module 4 micro carrier board with a multimodal Sensor Array and Wireless (uSAW) battery operation.

# Features

- Dual-camera inputs
- 9-axis IMU
- Stereo microphones
- GNSS module header (ZED GNSS)
- Stemma/QUIIC connector
- Power management
  - Battery charging & discharging
  - Fuel gauge
  - USB-C or L-ion power source
- SD card carrier
- UART Extension pins
- support for both Lite and eMMC variants of CM4
- USB C for power and USB 2.0 data transfer
- USB-OTG support
